## Selected work

### SteepSight
**A workspace for exploring data, from ingestion to analysis.**

Built an application for data profiling, filtering, visualisation, and regression analysis. Connected React with ASP.NET Core and FastAPI services through typed API contracts, with pandas and scikit-learn supporting the analysis workflows.

`React` `ASP.NET Core` `FastAPI` `Python` `pandas` `scikit-learn` `Plotly`

### Agentic Career Intelligence Platform
**AI-assisted workflows with human review built in.**

Exploring how retrieval, typed workflow contracts, and approval gates can help produce reviewable outputs and give users control over the next step.

`Agentic workflows` `Retrieval` `Typed contracts` `Approval gates`

### OpsPilot
**Retrieval-grounded AI chat with evaluation dashboards.**

Combining contextual AI responses with tools to examine response quality, understand limitations, and guide improvements.

`Applied AI` `Retrieval` `Evaluation`
